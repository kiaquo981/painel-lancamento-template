# Painel de lançamento

O trabalho inteiro vive no repositório-modelo `painel-lancamento-template`. Esta skill só leva você até ele.

1. **Localize o modelo.** Se o diretório atual tem `lancamento.config.json` e `AGENTS.md`, você já está num clone. Senão, pergunte à pessoa onde está o repositório-modelo (endereço do Git ou pasta local) e em que pasta criar o projeto, e clone para lá.
   **Pronto quando:** você está na raiz de um clone próprio deste projeto.
2. **Siga `AGENTS.md`** do clone, do passo 1 ao 5, sem pular o briefing.
   **Pronto quando:** o critério do passo 5 de `AGENTS.md` foi cumprido.
